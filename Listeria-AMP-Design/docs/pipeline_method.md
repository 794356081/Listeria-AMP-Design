# 方法学说明

本文档描述 `Listeria-AMP-Design` 四个计算阶段的设计原理、公式、参数依据与评价协议。所有描述均为中立的计算方法说明；流程输出是湿实验前的候选优先级参考，不构成活性、毒性或食品安全性结论。

---

## 1. 背景与设计目标

单增李斯特菌（*Listeria monocytogenes*）是典型的嗜冷性食源性致病菌，可在冷藏条件下持续繁殖，常见于肉制品、乳制品与即食食品。抗菌肽（antimicrobial peptides, AMPs）是具有潜力的天然防腐分子，但传统发现路径依赖合成与逐一活性测定，通量与成本限制了早期候选空间的探索。

本流程的目标不是预测某一序列的具体 MIC，而是在**湿实验之前**完成三件事：

1. 从已知抗菌肽的序列空间中定向生成大量 10–50 aa 短肽；
2. 用可解释的理化规则剔除明显不合理的序列；
3. 用蛋白质语言模型表征与多维评分，将候选范围收敛到可合成、可测定的规模，并给出透明的排序依据。

流程输出一个按综合得分排序的候选表，供使用者结合合成可行性、成本与实验条件选择后续验证对象。

---

## 2. 总体架构

```
参考肽序列
   │
   ▼
[1] ProtGPT2 定向生成 ──► 候选短肽库（FASTA）
   │
   ▼
[2] 理化初筛 ───────────► 通过序列 + 描述符表（CSV）
   │
   ▼
[3] ESM-2 表征 ─────────► 1280 维向量矩阵（NPY）
   │
   ▼
[4] 五指标评分排序 ─────► 候选排序表（CSV）
```

四个阶段通过文件系统解耦：每一阶段只依赖上一阶段的输出文件，便于单独替换、调试或复用。所有参数集中在 `config.yaml`，随机种子固定为 `project.seed`。

## 3. 模块一：定向短肽生成

### 3.1 模型与提示策略

使用 ProtGPT2（738M 参数的蛋白质语言模型）。与无条件采样不同，本流程从参考肽中长度为 10–50 aa 的序列提取 **N 端 3 aa 前缀**作为提示，使生成分布集中在已知抗菌肽的序列邻域。每个批次随机抽取 20 个前缀，每个前缀采样 10 条，共 200 条/批。

### 3.2 采样参数

| 参数 | 值 | 作用 |
|---|---|---|
| temperature | 0.85 | 在多样性与局部合理性之间折中 |
| top_p | 0.9 | 核采样，截断低概率尾部 |
| top_k | 40 | 限制每步候选词表 |
| repetition_penalty | 1.2 | 抑制重复片段 |
| max_new_tokens | 12/15/18/20 随机 | 控制生成长度分布 |
| 精度 | FP16（GPU）/ FP32（CPU） | 显存与速度 |

### 3.3 长度与质量控制

- 解码后只保留字母字符并转为大写；
- 超过 50 aa 的序列截断至 50 aa；
- 丢弃短于 10 aa 或含非标准氨基酸字符的序列；
- 与参考肽集合、已生成集合做精确去重，保证输出唯一。

### 3.4 断点续跑

生成结果逐条追加到 FASTA；每 `checkpoint_every_batches` 批写入一次进度 JSON。重启时从 FASTA 恢复已生成序列与最大编号，避免重复计算。该设计使十万级生成任务可以在有限显存与不稳定实例上分段完成。

## 4. 模块二：理化初筛

### 4.1 规则与阈值

| 规则 | 阈值 | 依据 |
|---|---|---|
| 长度 | 10–50 aa | 与短肽设计空间一致，兼顾膜活性与合成可行性 |
| 氨基酸组成 | 仅 20 种标准氨基酸 | 非标准残基无法由常规固相合成直接获得 |
| 连续重复 | 无 ≥5 个相同残基 | 降低低复杂度与聚集倾向 |
| 净电荷（pH 7.4） | −2 ～ +6 | 阳离子性是多数膜活性抗菌肽的特征，同时避免过强电荷带来的合成/溶解问题 |
| GRAVY | −1.5 ～ +1.0 | 排除过疏水或过亲水的极端序列 |
| 去重 | 输入内部 + 与参考肽 | 避免重复候选与已知序列泄漏 |

### 4.2 描述符定义

**净电荷**按 Henderson–Hasselbalch 关系逐残基求和：

```
q(pH) = 1/(1+10^(pH−pKa,N)) − 1/(1+10^(pKa,C−pH))
        + Σ_{K,R,H} 1/(1+10^(pH−pKa))
        − Σ_{D,E,C,Y} 1/(1+10^(pKa−pH))
```

N 端 pKa = 9.69，C 端 pKa = 2.34；侧链 pKa 取常用值（D 3.65、E 4.25、C 8.18、Y 10.07、H 6.00、K 10.53、R 12.48）。

**GRAVY** 为 Kyte–Doolittle 疏水标度的残基平均值。

**疏水矩 μH** 在 11 残基滑窗内计算，残基间旋转角取 100°（理想 α 螺旋）：

```
μH = max_w  sqrt( (Σ H_i cos(iθ))² + (Σ H_i sin(iθ))² ) / w
```

其中 H_i 为 Eisenberg 疏水标度，θ = 100°，w = min(11, 序列长度)。

**螺旋倾向 Pa** 为 Chou–Fasman 螺旋倾向标度的残基平均值；**阳离子残基比例**为 (K+R)/长度；**疏水残基比例**为 (A+V+I+L+M+F+W+Y)/长度。

分子量按残基单同位素质量求和并加一分子水；等电点用二分法求净电荷为零的 pH。

## 5. 模块三：ESM-2 表征

使用 `facebook/esm2_t33_650M_UR50D`。对每条序列取最后一层隐状态，对残基位置做平均池化：

```
e = (1/(L)) Σ_{i=1..L} h_i
```

池化时排除 BOS 与 EOS 位置（由 attention mask 与序列长度定位）。输出 1280 维 `float32` 向量。批次大小默认 100；显存不足时自动减半。矩阵以 memmap 方式写入，支持断点续跑。

表征前以参考肽表征的均值中心化：

```
x' = x − μ_ref,   μ_ref = mean(E_ref)
```

中心化用于削弱 ESM-2 嵌入中跨序列共享的公共分量，使余弦相似度更多反映序列间的相对差异。

## 6. 模块四：五指标评分

### 6.1 高活性参考集

从参考肽中取有 MIC 记录者，以 MIC 中位数（或配置的分位数）为阈值，定义高活性集。参考集的 ESM-2 向量经中心化、归一化后取平均，得到单位质心 `c`。

### 6.2 五个分量

| 分量 | 公式 | 权重 |
|---|---|---:|
| W1 ESM 相似度 | `pct( cos(x', c) )` | 0.45 |
| W2 阳离子两亲性 | `0.5·pct(cationic_ratio) + 0.5·pct(μH)` | 0.20 |
| W3 螺旋倾向 | `pct(Pa)` | 0.15 |
| W4 疏水平衡 | `exp(−((GRAVY − 0.2)/0.5)²)` | 0.10 |
| W5 低溶血 | `1 − P_hemolysis` | 0.10 |

`pct(·)` 为当前候选库内的百分位秩：

```
pct(v_i) = (rank_avg(v_i) − 1) / (N − 1)
```

因此 W1–W3 是**库内相对量**，而不是绝对活性预测。W4 以 GRAVY = 0.2 为中心、σ = 0.5 的高斯函数奖励接近最优两亲平衡的序列。

### 6.3 溶血风险

- 若参考肽中带溶血标签的样本 ≥ 16 且包含两类标签，使用 ESM-2 表征训练 L2 逻辑回归（`C=0.1`，`class_weight="balanced"`），以 5 折分层交叉验证估计区分度；
- 若交叉验证 AUC ≥ 0.60，则用全量标签重新拟合，输出候选的溶血概率；
- 否则退化为理化启发式：`0.40·pct(μH) + 0.25·pct(GRAVY) + 0.20·pct(net_charge) + 0.15·pct(hydrophobic_ratio)`。

W5 是排序中的温和惩罚项，不是安全性预测；标签规模有限时其不确定性较大。

### 6.4 综合得分

```
score = 100 × (0.45·W1 + 0.20·W2 + 0.15·W3 + 0.10·W4 + 0.10·W5)
```

权重反映设计优先级：序列空间相似性（W1）占主导，理化性质（W2–W4）提供可解释约束，溶血风险（W5）作为温和惩罚。权重可在 `config.yaml` 中修改；修改后应重新评估排序稳定性。

## 7. 评价协议

### 7.1 三组同预算对照

在相同采样预算（866 批 × 200 条 = 173,200 次采样）下比较：

- **A**：原始 ProtGPT2 采样（无长度约束）；
- **B**：定向生成 + 仅理化筛选与排序；
- **C**：完整管线（定向生成 + 理化初筛 + ESM-2 + 五指标评分）。

参考运行中，A 的 10–50 aa 产出率为 30.3%，B/C 为 57.8%；B/C 的理化初筛通过率为 54.2%。该对照用于说明长度定向策略对**有效短肽产出率**的影响，而不是活性优劣。

### 7.2 回顾性留出验证

- 从参考肽中取有 MIC 记录者，以训练折中位数（2.0 μg/mL）定义高活性集（35 条标准序列）；
- 5 折交叉，每折留出 7 条高活性肽；
- 以 54,181 条生成肽为背景池，按 ≥90% 序列相似度剔除与已知肽相近的背景序列（参考运行实际剔除 0 条）；
- 评分采用 W1–W4 四分量版本；W5 溶血模型不适用于已知肽，未纳入；
- 指标为 **Mann–Whitney AUC**：每折以 7 条留出高活性肽为正样本、背景池为负类，统计正样本得分高于随机背景肽的概率。

参考运行：完整体系 AUC 0.749，仅理化排序 0.753；Top1% 召回 17.1% vs 2.9%，Top5%/Top10% 为 48.6%/57.1% vs 31.4%/37.1%；5 折 AUC 范围 0.540–0.964（完整）与 0.626–0.906（仅理化）。以全局中位 MIC = 4.0 μg/mL 作灵敏度分析时，AUC 为 0.766 vs 0.679。

**指标解释边界**：背景池是未标注的生成肽，不是已确证的阴性肽。因此该 AUC 等价于"以未标注背景为负类的排序 AUC"，反映评分把高活性肽排到背景池前部的能力，不等同于基于确证阴性样本的标准分类 ROC-AUC。折间波动明显，不能据此声称完整评分全面优于仅理化排序。

### 7.3 评分消融

基于完整库的评分矩阵，复算五种权重方案，比较 Top100 与原完整体系的重叠与 Spearman 秩相关：

| 方案 | Top100 重叠 | Spearman ρ |
|---|---:|---:|
| S1 仅理化 | 23 | 0.647 |
| S2 理化 + ESM-2 | 43 | 0.984 |
| S4 五指标等权 | 53 | 0.843 |
| S5 强化 ESM 权重 | 67 | 0.973 |

结果表明 ESM-2 表征是影响排序的主要因素，名单对权重设置存在一定敏感性。该分析仅使用已存评分矩阵，不涉及新的实验或模拟。

## 8. 方法学优势与适用边界

### 8.1 相对传统随机筛选

- **定向性**：提示来自已知抗菌肽的 N 端片段，生成空间集中在目标序列邻域；同预算下 10–50 aa 有效短肽产出率由 30.3% 提升至 57.8%。
- **可解释的初筛**：长度、电荷、GRAVY、重复规则均有明确物理/合成依据，可逐条追溯剔除原因。
- **表征驱动的排序**：ESM-2 相似度补充了纯理化规则无法捕捉的序列模式；消融显示加入表征后 Top100 名单发生显著变化。
- **透明权重**：五个分量与权重公开，使用者可依据场景调整；所有中间量（描述符、W1–W5、溶血概率）均输出，便于复核。

### 8.2 适用边界

1. **只做优先级排序**：得分不代表 MIC、抑菌圈或体内效果；排序靠前只意味着在给定参考集与评分体系下更值得优先测试。
2. **库内相对性**：W1–W3 为百分位秩，替换候选库或参考集会改变分值，不能跨数据集比较绝对分数。
3. **参考集依赖**：高活性阈值、参考肽来源、菌株与 MIC 测定条件都会影响 W1；参考集过小或偏倚会放大不确定性。
4. **溶血模型为探索性**：标签数量有限，交叉验证区分度中等；W5 不构成安全性结论。
5. **模型偏差**：ProtGPT2 与 ESM-2 在天然蛋白质语料上训练，生成序列可能落在模型分布边缘；理化合理不等于可合成、可折叠或有活性。
6. **流程范围**：本仓库只覆盖生成、初筛、表征与评分。结构预测、膜对接、分子动力学等下游分析需另行开展，且同样属于计算层面证据。

## 9. 复现性

- 所有参数位于 `config.yaml`；命令行参数可覆盖模型路径、目标数量、设备等关键项。
- 随机种子由 `project.seed` 控制；在相同硬件、软件版本与种子下，生成与训练过程可重复。GPU 采样在不同 CUDA/cuDNN 版本间可能存在细微差异。
- 所有输入输出均使用相对路径；`runs/` 目录被 `.gitignore` 排除，避免提交运行产物。
- 每个阶段都写出 JSON 摘要（规模、阈值、耗时、剔除原因），便于审计与二次分析。
